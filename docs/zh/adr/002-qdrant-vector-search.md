# ADR 002 — Qdrant 作为向量检索引擎

- **状态**：已采纳
- **日期**：2026-06-01

## 背景

我们需要一款向量数据库，满足：

- 开箱即用支持 768 维向量（Sentence-BERT）
- 余弦 + 点积相似度
- 持久化存储
- 既可自托管也支持托管（Qdrant Cloud）
- 合理的运维复杂度

## 决策

采用 **Qdrant 1.9+** 作为主向量存储。

## 候选方案

| 方案      | 原因未选                                                         |
|-----------|-----------------------------------------------------------------|
| pgvector  | 与 Postgres 强耦合；在我们的规模下 kNN 更慢                    |
| Milvus    | 运维更重；Rust + Python 客户端易用性略差                        |
| Weaviate  | 依赖图更大；GraphQL 优先，但我们用不到                          |
| Pinecone  | 仅托管；厂商锁定；成本                                          |

## 后果

- Qdrant 对 Docker 友好，只需一个容器即可加入现有 Compose 栈。
- 模型维度可通过 `EMBEDDING_MODEL` 环境变量配置，因此自托管场景可以
  无需改动代码（仅需重建索引）地切换到更小的模型。
- `vector_search` 服务是唯一导入 `qdrant-client` 的地方，我们因此保留了在
  v1.2 增加后端抽象层的能力。
